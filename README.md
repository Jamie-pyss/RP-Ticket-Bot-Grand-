Deutsch

Der Bot dient dazu, RP‑Tickets zu festen Zeiten zu verwalten. Er sendet eine Nachricht mit drei Buttons: 10 Uhr, 16 Uhr und 22 Uhr. Wenn jemand auf einen dieser Buttons drückt, startet der Bot automatisch den entsprechenden Zyklus.
Nur Nutzer mit einer bestimmten Rolle dürfen die Buttons benutzen. Wenn jemand auf „Gewonnen“ drückt, wird der Nutzer in einer JSON-Datei gespeichert und der Bot beginnt automatisch Erinnerungen zu senden. Diese Erinnerungen laufen weiter, bis die nächste Stunde erreicht ist oder jemand auf „Eingesammelt“ drückt.
Der „Eingesammelt“-Button ist ebenfalls nur für bestimmte Rollen verfügbar. Wenn jemand darauf drückt, wird der Eintrag gespeichert und der Bot stoppt die Erinnerungen für diese Stunde.
Der Bot postet außerdem jeden Tag um 10:15, 16:15 und 22:15 die UI-Nachricht neu, damit sie immer oben steht. Alle IDs und Einstellungen werden in der config.json eingetragen. Der Bot liest diese Werte beim Start ein und verwendet sie für alle Funktionen.

English

The bot is used to manage RP ticket cycles at fixed times. It sends a message with three buttons: 10 AM, 4 PM, and 10 PM. When someone presses one of these buttons, the bot automatically starts the cycle for that hour.
Only users with a specific role are allowed to press the buttons. When someone presses “Won”, the bot logs the user into a JSON file and begins sending automatic reminders. These reminders continue until the next hour is reached or someone presses “Collected”.
The “Collected” button is also restricted to specific roles. When someone presses it, the action is logged and the bot stops all reminders for that hour.
The bot also reposts the UI message every day at 10:15, 16:15, and 22:15 so it always stays at the top. All IDs and settings are configured in the config.json file. The bot loads these values on startup and uses them for all functions.
